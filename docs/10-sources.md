## Reading order if you want to verify this repo

1. #1 (Dunlosky) — the spine.
2. #6 (Cepeda) and #3 (Rowland) — the two effects this repo is built on.
3. #33 (Wozniak) — the card-design rules.
4. #35–#39 (Anki docs) — the versioned facts, which are the ones most likely to
   be wrong in any guide written before 2026.
5. #26–#31 (AI and learning) — read the caveats, not just the headlines.

## A note on contested claims

Three claims in this repo are weaker than they look and are tagged accordingly:

- **AI-induced cognitive atrophy.** The MIT EEG result is small-n and
  pre-peer-review. The direction is consistent across studies; the magnitude is
  not established.
- **The medium of note-taking.** Mueller & Oppenheimer has had mixed
  replications. The robust claim is about *reformulation vs transcription*, not
  pen vs keyboard.
- **Desired retention for technical knowledge.** 0.85–0.90 is practice-based
  consensus. Nobody has run a controlled trial on optimal retention for
  programming knowledge specifically.

If you cite this repo, cite the primary sources, not the repo.
